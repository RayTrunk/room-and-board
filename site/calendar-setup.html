Add a calendar to your board

Paste up to 3 iCal feed URLs, then get a short code to type on your board (Settings → Calendar → Enter code). Works with Google Calendar, Apple iCloud Calendar, Nextcloud, and any standard .ics feed.

Google Calendar: Open Google Calendar → Settings → the calendar → "Integrate calendar" → copy the Secret address in iCal format (webcal://… link). Do not use the public iCal address — it only shows free/busy.

Apple iCloud: In Calendar.app → right-click a calendar → Share Calendar → enable Public Calendar → copy the link (webcal://…).

Nextcloud / other: Paste the https:// URL of your calendar's .ics export.
