title: Cloud Services
description: Status of the cloud services your office depends on, one row per service, with problems sorted to the top.
---

One row per cloud service your office depends on — Webex, Zoom, Slack,
Ubiquiti, Cloudflare, GitHub, Microsoft 365, Google Workspace, AWS, Claude
and OpenAI — read from each service's own public status page.

**Trouble sorts to the top.** A major outage outranks a minor issue, and both
outrank everything healthy, so the row that matters is never hidden behind a
"+N". When all is quiet the card shows your own chosen order. A degraded
service prints one line **per incident** — when Microsoft has three products
down, you see all three without tapping.

**Tap the card** for the full ledger: troubled services first with their
status text in full, everything healthy in quiet columns beneath.

## Configure

**Settings → Cloud Services.** Toggle services on and off. The card starts
with Webex, Slack and Microsoft 365.
