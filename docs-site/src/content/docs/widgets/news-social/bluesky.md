The latest posts from up to six Bluesky accounts, newest first. Like
[Substack](/docs/widgets/news-social/substack/), nothing is filtered — these
are your chosen authors.

**Tap the card** for the reading list.

## Configure

**Settings → Bluesky.** Type the handle — a one-tap `.bsky.social` key
finishes the common case. Handles are checked live as you add them.
