---
title: Set up your board
description: Build your dashboard on the board itself, from your phone, or from a desktop browser.
---

A board pointed at idlescreen shows a welcome screen until a configuration is
applied. (If the board isn't showing idlescreen yet, start with
[Getting it on the board](/docs/board/point-your-board/).)

There are three ways to build a configuration. All three reach the same
result, and none requires an account.

## On the board

Tap **Quick start** on the welcome screen. The board loads a default dashboard
immediately; adjust it by touch with the
<span class="glyph glyph--pencil" aria-hidden="true"></span> pencil
[editor](/docs/using/edit-your-layout/) and the
<span class="glyph glyph--gear" aria-hidden="true"></span> gear
[settings](/docs/using/settings/).

## From your phone

1. Scan the **QR code** on the welcome screen. It opens the setup page.
2. Choose your widgets, weather location, stations and lines.
3. Tap **Get my setup code**. You receive a six-character code.
4. On the board, tap **I have a setup code** and enter it.

## From a desktop browser

The same setup page is available at **idlescreen.app/setup** in any browser.
Build the configuration there, tap **Get my setup code**, and enter the code
on the board — on the welcome screen via **I have a setup code**, or on a
configured board via <span class="glyph glyph--gear" aria-hidden="true"></span>
gear → **Setup code**. This also suits setting up several boards to the same
pattern.

:::note[Codes]
A setup code is valid for one hour and can be used once. If a code expires,
generate a new one — the configuration you built is retained. See
[Setup codes explained](/docs/codes/setup-codes/).
:::

## After setup

Every setting remains editable on the touchscreen. The setup page is only
needed again to rebuild from scratch or to
[back up your board](/docs/codes/back-up-your-board/).
