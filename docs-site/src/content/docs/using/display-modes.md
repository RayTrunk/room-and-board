---
title: Display modes
description: "When the board shows the dashboard versus the screensaver: always one, always the other, or on a schedule."
---

**Settings → Display** decides what the board shows while it is idle: the
dashboard, the [screensaver](/docs/using/screensavers/), or each at its own
time of day.

## The three modes

| Mode | What the board shows |
| --- | --- |
| **Always dashboard** | The dashboard whenever the board is idle |
| **Always screensaver** | The screensaver whenever the board is idle |
| **Scheduled** | The dashboard during your chosen daily windows, the screensaver outside them |

## Scheduled mode

Scheduled mode takes up to four windows a day, in 15-minute steps — for
example, the dashboard during office hours and a clock face in the evening.

Outside every window, the board shows whatever
[screensaver](/docs/using/screensavers/) is selected.
